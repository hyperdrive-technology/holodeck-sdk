# Holodeck SDK examples

The [main README](../README.md#usage) contains a scene creation example, a
contribution registry example, and a JSON scene document.

For more usage patterns, see the colocated tests:

- [`index.test.ts`](../ts/src/index.test.ts): transforms, materials, scene validation,
  scene statistics, and scene construction.
- [`registry.test.ts`](../ts/src/registry.test.ts): kind registration, extension
  installation, pending contributions, and component pack conversion.

This directory currently contains only this guide. Editor examples belong in
[Holodeck](https://github.com/hyperdrive-technology/holodeck); this SDK has no CLI
or development server. See [CONTRIBUTING.md](../CONTRIBUTING.md) for setup and
verified test commands.
