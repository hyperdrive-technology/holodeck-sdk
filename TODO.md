# Holodeck SDK work tracking

Track work in [GitHub issues](https://github.com/hyperdrive-technology/holodeck-sdk/issues)
so contributors can see ownership, priority, and dependencies in one place.

- [M1 — Brewery on WASM](https://github.com/hyperdrive-technology/holodeck-sdk/milestone/1):
  support the brewery demo on the real Rust runtime compiled to WASM and consume
  Holodeck as built packages. Immediate SDK work:
  [registry atomicity (#6)](https://github.com/hyperdrive-technology/holodeck-sdk/issues/6).
- [M2 — Holodeck standalone scene builder](https://github.com/hyperdrive-technology/holodeck-sdk/milestone/2):
  shared scene and extension contracts for the standalone editor.

See [README.md](README.md#project-status) for the current state and
[CONTRIBUTING.md](CONTRIBUTING.md) for setup and checks. This file replaces the
old release checklist; it does not assert npm publication or test coverage.
